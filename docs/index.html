How it works

You paste your complete résumé once. After that, each job takes one click.

1

Open a job posting

On any site. Click the extension icon, then Generate résumé for this job.

2

Wait about a minute

A new tab shows the tailored résumé on an A4 sheet, written in the language of the posting.

3

Edit and save the PDF

Click any text to adjust it, check the page estimate, then Print / Save PDF.

Rules the model follows

A tailored résumé is only useful if it is still true.

Nothing invented

Claude selects, reorders and rewrites what is in your résumé. It does not add experience, skills or results you did not state.

Language of the posting

A posting in Spanish gets a résumé in Spanish, whatever language your source résumé or the interface is in.

The page is only data

Instructions hidden in the page text are ignored. Your own standing instructions can be added in settings.

Install

CV Matcher is in beta and not yet on the Chrome Web Store, so it is loaded by hand.

  1. Download the ZIP and unpack it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the src folder.
Download ZIP

Set up

The popup opens on setup the first time. Everything is saved as you type.

  1. Create an API key at platform.claude.com and paste it.
  2. Pick the Claude model. The popup shows the price of each one.
  3. Paste your full résumé as plain text or Markdown. The more complete it is, the better the selection for each job.

Privacy

  • There is no CV Matcher server, no account and no analytics.
  • Your API key and résumé are stored in chrome.storage.local, unencrypted, only in your browser.
  • Data is sent only to api.anthropic.com: your résumé, your instructions and the text of the posting, when you ask for a generation.
  • A page is read only when you click generate.

Cost and limits

  • Each generation is billed to your Anthropic account. Reloading or reopening a saved résumé never calls the API.
  • Only the last résumé is kept; a new generation replaces it.
  • Chrome's internal pages cannot be read, and postings inside an iframe may come through without text.
  • The on-screen page count is an estimate for A4 paper.

CV Matcher is an independent open source project, not affiliated with Anthropic.
